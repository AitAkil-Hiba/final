

# PEECO Frontend


Flutter application for local commerce platform connecting merchants with customers.


## 🚀 Quick Start


```bash
git clone https://github.com/gcmamel/Peeco.git
cd frontend
flutter pub get
flutter run
```


## 📱 Features


### Client Module
- Interactive map with merchant locations
- Exclusive offers with geolocation
- Real-time reservation system
- Favorites and filtering
- Client notifications
- Shopping cart


### Merchant Module  
- Offer management (CRUD)
- Reservation tracking
- Sales statistics
- Profile with legal documents
- Stock management


### Admin Module
- Merchant account verification
- User management
- Global statistics dashboard
- Legal document access


## 🛠️ Tech Stack


- **Flutter 3.11.5+**
- **Dart**
- **Go Router** for navigation
- **Provider** for state management
- **Flutter Map** for maps
- **SharedPreferences** for local storage


## 📦 Build


```bash
flutter run                    # Development
flutter build apk --release     # Android release
flutter build ios --release      # iOS release
```
